# Candidate validation

Local Node 22.23.4: clean install and Bash build passed. All eleven tests pass on Node 22.23.4 and 24.22.1. The update-hold checks cover startup, scheduled and HTTP updates, invalid settings, concurrent requests, and normal updates when unset or set to 0. Tests exercise synthetic WAV/DOA upload to localhost, retention on failure and retry, runtime rejection, and real local Git fetch/pull/reset with mocked install/restart commands. simple-git 4.0.2 is an intentional security major upgrade: its default export was removed, so the application uses the documented named export. Unsafe-operation guards remain enabled. HTTP/form-data/system-information and compatible transitive fixes are included. The production dependency audit still reports 24 affected packages (17 high, 6 moderate, 1 low), primarily the existing npm 10/nodemon/tooling/cron chains; no forced major dependency fix was used. USB/audio hardware, service restart, reboot and actual fleet versions remain unverified.

Status: draft candidate, not production deployed. See the [canary and rollback runbook](node-security-2026-10.md). GitHub checks must pass on the final commit before approval. All test fixtures are synthetic and do not use production credentials. The audit counts are package/advisory findings, not proof of exploitability or a guarantee that unreported vulnerabilities do not exist.
